# GraalVM Support

At its core, GraalVM is an open source project supported by a large community.
Community-driven support channels include:

- [GraalVM Documentation]({{ '/latest/docs/' | relative_url }})  
  *Learn how to take advantage of GraalVM.*
- [GraalVM on GitHub](https://github.com/oracle/graal){:target="_blank"}  
  *Open [issues](https://github.com/oracle/graal/issues){:target="_blank"} for bug reports or feature requests, start [discussions](https://github.com/oracle/graal/discussions){:target="_blank"}, and [contribute]({{ '/community/contributors/' | relative_url }}) to GraalVM.*
- [GraalVM on Slack]({{ '/slack-invitation/' | relative_url }})  
  *Chat with the people that build GraalVM, discuss your ideas, get help, and help others.*
- [GraalVM mailing list](https://oss.oracle.com/mailman/listinfo/graalvm-users){:target="_blank"}  
  *Subscribe and post to [`graalvm-users@oss.oracle.com`](https://oss.oracle.com/mailman/listinfo/graalvm-users){:target="_blank"}.*

## Commercial Support

**End of support for Oracle GraalVM in Java SE products**: Oracle GraalVM for JDK 24 was the final version of Oracle GraalVM licensed and supported as part of Oracle Java SE products. Any entitled customers seeking patches or updates to previously released Oracle GraalVM versions should download them through [MOS](https://support.oracle.com/knowledge/Oracle%20Linux%20and%20Virtualization/2605759_1.html){:target="_blank"}. More information is available [here](https://blogs.oracle.com/java/post/detaching-graalvm-from-the-java-ecosystem-train){:target="_blank"}. Customers seeking additional information or assistance should contact [MOS](https://www.oracle.com/support/){:target="_blank"}.

## Security Vulnerabilities

Security vulnerabilities of any kind in either Oracle GraalVM or GraalVM Community Edition should only be reported via email to [secalert_us@oracle.com](mailto:secalert_us@oracle.com).
