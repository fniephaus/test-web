Support

Oracle GraalVM publishes feature releases monthly on the innovation release line to preview new capabilities and collect early feedback before they are considered for a future LTS release. For planned release dates, see the Oracle GraalVM release calendar.

Available Distributions

Oracle GraalVM innovation release is available for Linux and Windows on the x64 architecture, and for Linux and macOS on the AArch64 architecture.
